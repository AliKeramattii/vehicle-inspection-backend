## پیشنهادهای معماری منتظر بازبینی بستهٔ Phase 0

یک پروژهٔ API با دو پروژهٔ تست، ADO.NET پارامتری، ۱۷ جدول تدریجی، manifest قالب ثابت و snapshot به‌جای مدیریت قالب کامل، منشأهای ستونی Info، cookie با SQL ticket store، ادغام فرمان‌های ویرایش خودرو در information و whole-file retry پیشنهاد شده‌اند. این‌ها الزامات ازپیش‌تأییدشده معرفی نمی‌شوند. اگر بازبینی آن‌ها را تغییر داد، PLAN و docs مرتبط در یک تغییر همسو اصلاح شوند.

2D در دامنهٔ قرارداد/reader ساختگی تکمیل و پیشرفت **19%** است. هیچ بستهٔ SQL لازم یا اضافه نشد؛ O24 همچنان برای SQL runtime باز است و گراف فعلی/lockfileها تغییر نکردند. O26 برای حساب‌های واقعی، O01/O09/O20–O22 برای mapping/validation و O03/O18 پیش از انتشار بازند؛ [audit امنیت foundation](checkpoint1/DEPENDENCY_SECURITY_FA.md) پاک نشده است. 2D فقط سیاست fixture، timestamp دریافت و fail-closed را اثبات می‌کند؛ source freshness، موبایل verified و SQL واقعی را ثابت نمی‌کند. گام بعد طرح 2E با مجوز جداست؛ برآورد مشروط تا ۲۰٪، بدون امتیاز فعلی. auth/OTP/Session/Info/media خارج scope باقی‌اند.
